# hamzahasann.github.io

Personal website built with **Astro 7** and **Bun**.

## Development

```bash
bun install
bun run dev      # http://localhost:4321
bun run build    # static build -> docs/
bun run preview  # preview the build
```

## Deploy

```bash
./deploy.sh
```

Builds into `docs/` and pushes to `main`. GitHub Pages serves `main` / `docs` at:

https://hamzahasann.github.io/
